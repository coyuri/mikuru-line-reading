# みくるの占い LINE LP

無料2ページ・有料7ページの全9枚を掲載する静的LPです。相談と鑑定書受け取りをLINEへ誘導し、有料決済のみ外部購入ページを使用する実際の流れを案内します。価格・納期・実績・利用者の声は創作せず、料金はLINEから案内される購入ページで確認する構成です。

## 画像

架空の仕事相談を使った既存検証サンプルをもとに、画像編集で本文・要約・プロフィール・運命コードの個別値をモザイク化しました。カレンダーはスコアとプロットも隠しています。掲載用WebPはモザイク適用後の画像から作成し、元の無加工画像はdistへ入れていません。見出しは画像編集により微細な差が生じる場合があります。

全9枚の目視確認、PCと390px幅のブラウザー確認、画像拡大・閉じる操作、LINEボタンURLの確認を実施しました。LINEへの実送信・購入操作はしていません。

公開資材はdistのみです。新しいSitesは本人確認用の非公開範囲で作成しています。
